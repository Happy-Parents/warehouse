# Tasks: Expo Mobile Foundation

**Input**: Design documents from `/specs/001-expo-mobile-foundation/`

**Prerequisites**: plan.md (required), spec.md (required for user stories), research.md, data-model.md, contracts/, quickstart.md

**Tests**: Included. The specification mandates them (FR-007: one rendering test per placeholder screen, a secure-storage round-trip test, an HTTP base-address test; FR-008: an automated hard-coded-string check).

**Organization**: Tasks are grouped by user story so each story is an independently verifiable increment. Because this feature is a foundation, Phases 1 and 2 are larger than usual; they carry everything every story needs.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies)
- **[Story]**: Which user story this task belongs to (US1 to US6, matching spec.md)
- Include exact file paths in descriptions

## Path Conventions

Single Expo project at the repository root (plan.md "Structure Decision"). Application code under `src/`, routes under `src/app/`, tests colocated as `*.test.ts(x)` next to the module they cover. `ios/` and `android/` are generated by prebuild and gitignored.

## Fixed versions (from research.md; do not substitute)

Expo SDK 58 (`expo@~58.0.21`, React Native 0.88.1, React 19.3.0), `@nozbe/watermelondb@0.28.0` + patch, `@morrowdigital/watermelondb-expo-plugin@2.4.0-beta.0`, `nativewind@4.2.7` + `tailwindcss@^3.4.19`, `ky@^2.2`, `i18next@^26` + `react-i18next@^17`, `jest-expo@~58` on Jest 30, `@testing-library/react-native@^14`, ESLint 9 + `eslint-config-expo@~58`, `typescript@~6.0.3`, `patch-package@^8`. Use `npx expo install <pkg>` for every Expo-managed package and plain `npm install` for the rest.

## Dependencies & Execution Order

### Phase Dependencies

- **Setup (Phase 1)**: No dependencies. T001 → T002 → T003 → T004 → T005 → T006 are sequential (each needs the previous install state); T007 to T012 are parallel after T006.
- **Foundational (Phase 2)**: Depends on Setup. T013 to T018 parallel; T019 after T016 and T018; T020 to T022 parallel; T023 after them; T024 then T025; T026 last. BLOCKS all user stories.
- **User Stories (Phase 3 to 8)**: All depend on Phase 2. Priority order P1 → P6 is the recommended sequence; see story dependencies below.
- **Polish (Phase 9)**: Depends on every story the team chooses to ship.

### User Story Dependencies

- **US1 (P1)**: After Phase 2 only. Produces the Home screen and the first native build.
- **US2 (P2)**: After Phase 2; T044 (Home test) needs US1's `src/app/index.tsx`. Everything else in US2 is independent of US1.
- **US3 (P3)**: After Phase 2; navigation target of US1's Button. Independently testable via `renderRouter` and a direct `/settings` launch.
- **US4 (P4)**: After US1 and US3 (it audits their screens). Lint rule itself (T049) only needs US2's `eslint.config.js`.
- **US5 (P5)**: After US1 (needs a buildable app). Independent of US2 to US4.
- **US6 (P6)**: After US1 and US3 (verifies both screens on Android). Independent of US2, US4, US5.

### Within Each User Story

- Configuration before code, code before device verification, device verification before README text that describes it.
- Tests may be written in parallel with the module they cover ([P] marked) but T045 (green gate) runs last in US2.

### Parallel Opportunities

- Phase 1: T007, T008, T009, T010, T011, T012 together after T006.
- Phase 2: T013 to T018 together; T020 to T022 together; T024 with any of them.
- US2: T032, T033, T034, T036, T037, T038, T040, T041, T042, T043, T044 all touch different files and can be authored together; only T035, T039 and T045 are ordered.
